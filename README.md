# Banking Risk Analytics Dashboard

An end-to-end data analytics project using Python, MySQL, and Power BI to explore banking customer profiles, loan exposure, deposits, and financial trends.

## Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **MySQL:** Data cleaning, joins, aggregations, primary and foreign keys, views
- **Power BI:** Data modeling, DAX measures, KPIs, interactive dashboards

## Project Workflow
1. Performed Exploratory Data Analysis (EDA) using Python.
2. Cleaned and structured banking customer data using MySQL.
3. Created relational tables and SQL views for analysis.
4. Developed DAX measures to calculate banking KPIs.
5. Built interactive Power BI dashboards for loan, deposit, and customer analysis.

## Key KPIs
- Total Clients
- Total Loans
- Total Deposits
- Bank Loans & Business Lending
- Credit Card Balances
- Total Processing Fees
- Customer Engagement

## Dashboards
- Home Dashboard
- Loan Analysis
- Deposit Analysis
- Summary Dashboard

## Project Scope
This project focuses on exploratory banking risk analysis and financial portfolio insights. It does not implement a machine learning model for predicting loan defaults.
